---
description: 审核待定夺的用户/工作区记忆
---

运行 `companion.py memory review --host <当前宿主> --scope all`，然后用选项 + 自由回答的方式让用户定夺。宿主未指定时先设置 `PROGRAMMER_WORKFLOW_HOST`；不同宿主的数据根互不共享。

要求：

1. 先给数量与分组，不要一次倾倒全部 JSON。
2. 每条显示：id、类型、文本、证据、置信度。
3. 先问整体处理方式：逐条审核 / 全部保留 / 全部不保留 / 稍后。
4. 逐条时允许用户用编号回复“保留 1 3，改 2，删 4”。
5. 应用后重新渲染并复述生效条目。
